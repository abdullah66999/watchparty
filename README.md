# 🍿 WatchParty — Смотри видео вместе с друзьями

> Синхронный просмотр видео с **YouTube**, **VK Видео**, **Google Диска** и **прямых ссылок (MP4/WebM)** с авторизацией через **Google**, встроенным чатом с таймкодами и голосовой связью (WebRTC) на чистом Node.js + WebSockets.

---

## ✨ Возможности

* 🔄 **Идеальная синхронизация:** Состояние воспроизведения (Play / Pause / Seek) синхронизируется у всех участников комнаты в реальном времени.
* 📺 **Поддерживаемые источники видео:**
  * **Google Диск** — вставьте ссылку на файл `drive.google.com/file/d/...`, сервер автоматически стримит видеопоток с поддержкой быстрой перемотки.
  * **YouTube** — воспроизведение по ссылке или встроенный поиск роликов прямо в плеере.
  * **VK Видео** — мгновенное воспроизведение роликов и клипов по прямой ссылке.
  * **Прямые ссылки (MP4 / WebM)** — нативный HTML5-плеер для любых видеофайлов из интернета/CDN с покадровой синхронизацией.
* 👤 **Вход через Google:**
  * Быстрая авторизация в 1 клик через Google Identity Services.
  * Настоящее имя и аватарка пользователя автоматически отображаются в списке гостей и возле сообщений в чате.
* 💬 **Синхронный чат:** Общайтесь в процессе просмотра с автоматической привязкой сообщений к текущему таймкоду видео и аватарками авторов.
* 🎙 **Голосовой чат (WebRTC):** Прямая голосовая связь прямо в браузере без сторонних приложений (Discord/Telegram).
* 👑 **Умный хост:**
  * Права управления плеером у создателя комнаты.
  * Возможность быстрой передачи хоста любому участнику («передать лидерку»).
  * Защита от потери хоста при кратковременном обрыве связи (`orphanHostCid` сохраняет права за вернувшейся вкладкой в течение 60 секунд).
* ⚡ **Zero-bloat стек:** Без тяжелых фронтенд-фреймворков и лишних зависимостей. Быстрая загрузка и минимальное потребление ресурсов.

---

## 🛠 Стек технологий

* **Backend:** Node.js (HTTP + WebSockets `ws`), Google Drive Stream Proxy, WebRTC Signaling
* **Frontend:** Vanilla JavaScript (ES6+), Google Identity Services (GSI), HTML5 Video, CSS3, YouTube IFrame API, VK Video Embed
* **Тестирование:** Puppeteer

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/abdullah66999/watchparty.git
cd watchparty/watchparty
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск сервера
```bash
npm start
```

Сервер запустится по адресу: **`http://localhost:3000`**
