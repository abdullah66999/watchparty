# 🍿 WatchParty — Смотри видео вместе с друзьями

> Синхронный просмотр видео с YouTube и VK Видео, встроенный реалтайм-чат с таймкодами и голосовая связь (WebRTC) на чистом Node.js + WebSockets.

---

## ✨ Возможности

* 🔄 **Идеальная синхронизация:** Состояние воспроизведения (Play / Pause / Seek) синхронизируется у всех участников комнаты в реальном времени.
* 📺 **Два источника видео:**
  * **YouTube** — воспроизведение по ссылке или встроенный поиск роликов прямо в плеере.
  * **VK Видео** — мгновенное воспроизведение роликов и клипов по прямой ссылке.
* 💬 **Синхронный чат:** Общайтесь в процессе просмотра с автоматической привязкой сообщений к текущему таймкоду видео.
* 🎙 **Голосовой чат (WebRTC):** Прямая голосовая связь прямо в браузере без сторонних приложений (Discord/Telegram).
* 👑 **Умный хост:**
  * Права управления плеером у создателя комнаты.
  * Возможность быстрой передачи хоста любому участнику («передать лидерку»).
  * Защита от потери хоста при кратковременном обрыве связи (`orphanHostCid` сохраняет права за вернувшейся вкладкой в течение 60 секунд).
* ⚡ **Zero-bloat стек:** Без тяжелых фронтенд-фреймворков и лишних зависимостей. Быстрая загрузка и минимальное потребление ресурсов.

---

## 🛠 Стек технологий

* **Backend:** Node.js (HTTP + WebSockets `ws`), WebRTC Signaling
* **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3, YouTube IFrame API, VK Video Embed
* **Тестирование:** Puppeteer

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/abdullah66999/watchparty.git
cd watchparty/watchparty
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск сервера
```bash
npm start
```

Сервер запустится по адресу: **`http://localhost:3000`**
